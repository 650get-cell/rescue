Scheduler — Change Log Summary
Session recorded May 2026  ·  Replit Agent

Features & Changes

1
Feature Infinite Calendar Scroll
Replaced the fixed 4-month snapshot with infinite scroll. Months load automatically as you scroll down or up (up to 3 years back). Arrow buttons jump 3 months at a time. The month label in the header updates live as you scroll.
2
UI Consistent Month Header Size
Fixed the navigation label between the ← → arrows to a fixed width (130 px, centered) so short month names like "May" and long ones like "September" no longer shift the arrow buttons.
3
Feature Job Pill Scrolls to Start Month
Clicking a job pill in the ribbon now automatically scrolls the calendar to the first month of that job, so you land right at the beginning of the engagement.
4
Fix Job Ribbon Disappearing
Two root causes fixed: (a) replaced scrollIntoView — which scrolled the whole page — with a targeted wrap.scrollBy that only moves the calendar panel; (b) locked html/body with overflow:hidden so the page can never scroll and carry the ribbon off-screen.
5
Fix "Create Job" Button Always Visible
Moved the Create Job and Cancel buttons to the top of the new-job form (directly below the name field) so they are always in view without needing to scroll, regardless of screen height.
6
UI Collapsible Job Section + Label Cleanup
The sidebar "Configure job" section was renamed to Job. Clicking the label collapses or expands the entire section (▼/▶ toggle). The redundant "CLIENT NAME" heading inside the form was removed; the input placeholder now reads "Job name…"
